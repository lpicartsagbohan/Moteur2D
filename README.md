# Moteur2D
Developed as an academic project, this repository serves as an introduction to 2D game engines, where I co-developed a custom engine from scratch using the SDL library alongside Killian Mermin.

**Important:** Before launching the game, please download [`lib.zip`](https://github.com/lpicartsagbohan/Moteur2D/releases/tag/moteur2D) and extract both `Assets.zip` and `lib.zip` directly into the project's root folder.
